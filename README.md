# Asami Sushi — Landing Page Oficial

Landing page de alta conversão nível Awwwards SOTD desenvolvida sob o conceito **Afluência** para o restaurante **Asami Sushi** em Santo André - SP.

## Destaques de Arquitetura & Design
- **100% Vanilla (Zero Dependências):** Plain HTML5, CSS3 moderno e Vanilla JavaScript.
- **Hero Cinematográfico (250vh):** Sticky pin stage com lerp dt-normalizado, fade progressivo e tipografia com split words.
- **Ritual Interativo:** Arrastar físico da chaleira liberando névoa volumétrica em canvas 2D.
- **Comanda da Despreocupação:** Transparência de preço único fixo (R$ 130 por pessoa com bebidas e sobremesas inclusas).
- **Esteira Horizontal Virtual:** Virtual scroll panorâmico com momentum decay (0.90) e wheel guard.
- **SEO & Performance:** Schema.org LocalBusiness JSON-LD, Open Graph, meta tags otimizadas e `fetchpriority="high"` / `loading="lazy"`.
- **Acessibilidade:** Suporte completo a `prefers-reduced-motion`, contraste auditado e navegação drawer mobile para telas pequenas.

## Stack
- HTML5 semântico
- CSS3 (Custom properties, Grid, Flexbox, Clamp typography)
- Vanilla JavaScript (rAF, IntersectionObserver, Canvas API)
- Vercel Static Deploy
